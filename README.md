# 带键盘事件的计算器

Qt 6 课程实验一：实现一个支持四则运算、小数输入、退格、清除以及键盘输入的计算器。

## 功能

- 加减乘除四则运算，支持小数输入
- 退格（⌫）与清除（C）
- 鼠标点击与键盘输入复用同一套处理逻辑
- 边界处理：除数为 0、连续小数点、连续运算符、连续运算、计算结果后继续输入
- QSS 样式表美化界面

## 构建

```bash
qmake calculator.pro
make            # Windows 下为 mingw32-make
```

## 键盘操作

| 按键 | 功能 |
|------|------|
| 0-9 / 小数点 | 输入数字与小数 |
| + - * / | 运算符 |
| Enter / = | 等号 |
| Backspace | 退格 |
| Esc / Delete | 清除 |
