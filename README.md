# 简单文本编辑器

Qt 6 课程实验二：一个多窗口的简单文本编辑器，支持文件读写、编辑操作、查找替换、字体与背景设置等。

## 功能

- 文件：新建、打开、保存、另存为，未保存修改关闭时提示
- 编辑：撤销、重做、剪切、复制、粘贴、全选
- 查找 / 替换对话框（支持区分大小写、查找下一个、替换、全部替换）
- 格式：字体大小、字体颜色、背景颜色、自动换行
- 视图：显示 / 隐藏工具栏、状态栏、行号（行号通过继承 QPlainTextEdit 实现）
- 窗口标题随修改状态自动加 `*`
- 剪切/复制/粘贴/撤销/重做等 Action 的使能状态与编辑状态一致

## 构建

```bash
qmake texteditor.pro
make            # Windows 下为 mingw32-make
```

## 结构

| 文件 | 说明 |
|------|------|
| mainwindow.cpp | 主窗口，文件/编辑/格式/视图/帮助逻辑 |
| codeeditor.cpp | 继承 QPlainTextEdit 实现行号显示 |
| finddialog.cpp | 查找/替换对话框 |
